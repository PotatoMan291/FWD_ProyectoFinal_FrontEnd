# PuraVida Trips

PuraVida Trips es una plataforma web de booking turístico enfocada en la búsqueda, comparación y reserva simulada de tours y experiencias turísticas en Costa Rica.

## Tecnologías

- React + Vite
- React Router DOM
- JSON Server
- JavaScript
- CSS
- Git y GitHub

## Estructura

```text
src/
├── components/
├── pages/
├── routes/
├── services/
├── App.jsx
├── main.jsx
└── index.css

docs/
db.json
```

## Instalación

```bash
npm install
```

## Ejecución

Frontend:

```bash
npm run dev
```

JSON Server:

```bash
npm run server
```

El frontend utiliza `http://localhost:5173` y JSON Server `http://localhost:3001` durante el desarrollo local.

## Documentación

La carpeta `docs/` contiene el anteproyecto, la guía de marca, el enunciado general del proyecto y la rúbrica de evaluación.
